5. START TRIP VERIFICATION
==========================

When student clicks START TRIP:

* open front camera automatically
* detect human face using MediaPipe
* capture ONE live image
* compare with registered student image stored in DB

If MATCHED:

* mark student status:
  "AVAILABLE IN BUS"
* save trip start timestamp
* mark assigned seat occupied
* save verification result in PostgreSQL
* stop camera stream
* show success message

If NOT MATCHED:

* reject verification
* save suspicious image
* save suspicious attempt log
* notify conductor dashboard
* notify admin dashboard
* notify genuine student:
  "Another person may be occupying your assigned seat."

==================================================
6. END TRIP VERIFICATION
========================

When student clicks END TRIP:

* open front camera again
* capture live image
* compare with registered student image

If MATCHED:

* mark final attendance PRESENT
* save trip end timestamp
* mark seat empty
* save full attendance history

If NOT MATCHED:

* reject attendance completion
* create suspicious activity log
* notify admin and conductor dashboards
